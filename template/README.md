# life

My lists, as plain text in git: to-dos, shopping, ideas, habits, reading, quotes. Built with [life-in-git](https://github.com/mteyra/life-in-git).

| File | What's in it |
| --- | --- |
| [`inbox.md`](inbox.md) | everything captured, not yet sorted |
| [`todo.md`](todo.md) | all tasks |
| [`projects/`](projects/README.md) | background and ideas per project |
| [`lists/`](lists/) | shopping, reading, watch, wishlist, places |
| [`habits/`](habits/habits.md) | what I track, and the log |
| [`quotes.md`](quotes.md) | favourite quotes |
| [`reviews/`](reviews/README.md) | weekly reviews |
| [`done.md`](done.md) | finished things |

Add things from the phone (Shortcuts), the laptop (`life.py`), or by editing the files. Formats: [FORMAT.md](https://github.com/mteyra/life-in-git/blob/main/FORMAT.md).
